# Data for B3
Women's E-Commerce Clothing Reviews (Kaggle). Not committed to GitHub.
Download: `kaggle datasets download -d nicapotato/womens-ecommerce-clothing-reviews --unzip -p data/`
(needs a Kaggle API token), or download the CSV manually from
https://www.kaggle.com/datasets/nicapotato/womens-ecommerce-clothing-reviews and put it in this folder.
